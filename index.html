    旅 程 指 引

    你要走的路,都画在这张地图上。四件事记牢:

    1. 看地图 —— 世界地图标出全部 15 处地区,并给出彼此之间的里程与预计耗时。 顶上带「剧情在此」的地方,就是当前该去的地方。
    2. 赶路要花真实时间 —— 距离越远,行进越久(约 1~3 分钟,最远 5 分钟)。 装备载具能大幅缩短耗时:老马 ×0.75、板车 ×0.55、快马 ×0.45、快帆船 ×0.38、风翼 ×0.30。
    3. 主城之间可穿梭 —— 身处主城时,可花金币瞬间抵达另一座主城,代价随里程递增。 不在主城就先步行过去。
    4. 路上不太平 —— 途中会随机遇到该地区等级的怪物(可战斗夺金), 也会遇到形形色色的路人 NPC。点本地人物或路上遇到的客人,先从若干话题里挑一句说出去, 对方会就着这一话题作答(一次交谈至多 5 句)。
    5. 宝箱要问密码 —— 后段章节的地点藏有上锁宝箱(地图上标 🔒)。 和本地人「问问传闻」时,有人会透露宝箱密码与位置;记下后点「情报」回看, 再到宝箱处输入三位数密码开箱。

    游 戏 说 明

    剧情推进

    • 点击文本/空格/回车 推进剧情；文字正在渐显时点击可立即显示全部
    • 1~9或点击选项 做出抉择(选项会在段落读完后浮现)

    卡牌对战

    • 点击手牌 打出卡牌,消耗能量;能量不足的牌会变暗
    • 结束回合/空格/回车 结束本回合,进入敌方的行动
    • 敌人意图 ⚔ 攻击 · 🛡 防御 · ✦ 强化
    • 状态效果 易伤 / 虚弱 / 脆弱 为减益,力量 为增益
    • 魔力 ✦ 稀有卡额外消耗 1 点魔力,战斗开始时回满
    • 战力 ⚔ 由武器与服饰加成,直接提升攻击牌伤害
    • 战斗中用药 手牌下方列出药品,点击即用,不消耗回合

    地图与探索

    • 地区地图 每章是一处地区,含 3 个地点;按剧情提示前往指定地点、找到关键 NPC。地图左下角常驻你的人物形象,随换装变化
    • 旅行 在地图上行进会消耗行动力,载具可降低消耗
    • 开启剧情 抵达目标地点后,点「开始剧情」才会推进故事——不能跳章

    世界地图与旅途

    • 世界地图 共 15 处地区全部标注在地图上,每处都标出里程、预计耗时与敌人等级;标「剧情在此」的就是当前该去的地方
    • 启程 点地图或清单里的地区 → 「启程前往」,消耗行动力,并按里程消耗真实时间(约 1~3 分钟,最远 5 分钟)
    • 载具 在商店购买并装备,既缩短旅途耗时又降低行动力消耗。载具分地形:老马 ×0.75 / 板车 ×0.55 / 快马 ×0.45 / 雪豹 ×0.34 走陆地·高原;快帆船 ×0.38 / 轮船 ×0.30 走海面·港口;风翼 ×0.30 走陆地·高原·浮空;飞艇 ×0.18 可飞跃全部地区。载具走不了的地形无法启程(徒步不限地形)
    • 穿梭 身处主城时,可花金币瞬间抵达另一座主城,费用随里程递增
    • 途中遭遇 赶路途中会随机遇到该地区等级的怪物(可战斗夺金),也会遇到路人 NPC 搭话
    • 随机 NPC 每个地点有数位随机人物,点击「本地人物」即可交谈:先选一句你想说的话(打招呼 / 打听此地 / 问传闻 / 聊聊对方),对方会就着这一话题作答,一次至多 5 句(共 70 位)
    • 宝箱与情报 后段章节的地点藏有上锁宝箱(地点卡上标 🔒)。密码由部分 NPC 在「问问传闻」时透露 —— 得到后点地图上的「情报」随时回看,再到宝箱处输入三位数密码开箱,可得金币与道具

    金钱与物资

    • 金币 🪙 战斗、出售物品与打工获得,用于在商店买入
    • 行动力 ⚡ 旅行与打工消耗;推进剧情、吃食品、酒店休息可恢复,本地人有时也会赠些干粮;通关一大章行动力回满
    • 背包 拾取 / 使用 / 装备 / 丢弃物品;在商店可出售
    • 装备 武器(战力);帽子 / 衣服 / 裤子 / 鞋子可自由搭配,改变外观,部分服饰带特殊增益(折扣 / 金币 / 休息);载具(降低旅行消耗)
    • 皇帝的新衣 四件套凑齐会「衣不蔽体」:在主城可能被巡卫逮住处以巨额罚款(按身上金币比例);在野外赶路则会大幅招来更高等级的怪物 —— 想穿就趁夜里赶路
    • 市场 🧺 与「商店」并列的玩家集市:全品类货物由不同玩家设摊发售,也可在这里卖掉背包里的东西;每笔交易额外收 10% 管理费(买贵一点、卖少一点)
    • 密市与交易币 部分地区随机会有一处隐秘集市(走到该地点时地图上会出现「密市」按钮)。密市只收当地主题的特殊交易币(谷币 / 松脂珠 / 雪晶 / 银筹 / 贝壳币 / 云绵石 / 残碑片 / 崖铁钉 / 营灰印),管理费 5%~70% 不等,货架上还可能摆出绝世稀有的兵器、服饰与药品。交易币可从宝箱、剧情推进与该地打工中获得(概率 30%~90%)
    • 加速药水 醒神香 / 长明香把之后在酒店休整的耗时缩到四分之一;疾风饮让下一段旅途耗时减半 —— 等不起时先喝一口
    • 邮箱 📮 右下角圆形图标打开邮箱,读取来信;带奖励的信件点「领取」即可入袋;每通关一大章,驿站都会寄来一封「通关谢仪」
    • 回忆 📖 左下角圆形图标打开「回忆」,回看已通关大章的剧情回顾;当前进行中的一章与尚未解锁的章节也会标出
    • 衣橱 🧥 左下角圆形图标打开「衣橱」,为七个防具部位挑选背包中防具的外观(纯装饰,不给数值,可随时换、可隐藏);防具的实际数值须在「角色」的装配位生效,装配位不改变外观
    • 兑换码 🎁 右下角圆形图标打开兑换码,输入礼包码换取金币 / 物品;同一台设备上每个码限兑一次
    • 打工 在部分地点玩一局小游戏(拾取 / 躲避 / 跑酷),达标才消耗行动力并发放金币;三档难度,金币越多越难
